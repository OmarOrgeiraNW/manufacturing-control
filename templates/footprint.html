How it works

Upload one or more parts already oriented for printing — the build direction is Z (vertical). Set the quantity for each part, then click Analyse.

The tool projects each part's 3D body onto the XY build plate, packs all requested copies using a shelf algorithm, and assesses whether they all fit.

STL — exact silhouette via trimesh (handles binary, ASCII and multi-solid files).

STEP — convex hull of extracted vertices. For maximum accuracy upload an STL.
